# 日语界面术语

[English](japanese-ui-terms.md) | 中文

日语文案应当说清操作的作用和状态的含义。审阅时结合英文、中文原文及所属操作，保留占位符、命令名和 API 标识。同一个英文词在不同功能中可以采用不同的日语表达。

## 已审阅的术语

| 语境 | 英文 | 日语 | 依据 |
| --- | --- | --- | --- |
| 目标等待继续 | Inactive goal | 再開待ちの目標 | 目标仍然保留，可以继续执行。 |
| 解除会话目标 | Clear goal | 目標を解除 | 直接说明对目标的操作。 |
| 尚未发送的消息 | Queue | 送信待ち | 说明消息所处的发送状态。 |
| 给运行中的任务追加指示 | Steer | 実行中のタスクに指示を追加 | 解释操作，无需学习新的动词。 |
| 清空搜索条件 | Clear search | 検索条件を消去 | 明确清除的对象。 |
| 清除已结束的后台任务 | Clear finished jobs | 終了したジョブを消去 | 包含失败和取消的任务。 |
| 查看运行记录 | Trajectory | 実行履歴 | 对应用户打开的事件记录。 |
| 任务板的负责人 | Owner | 担当 | 指负责该任务的智能体。 |
| 尚未开始的任务 | Pending | 未着手 | 与暂停状态区分。 |
| 配置的缺省值 | Default | 既定値 / 既定 | 说明未选择时采用的值。 |
| 恢复快捷键配置 | Reset to default | 初期設定に戻す | 说明恢复已保存的按键分配。 |
| 复制单行 JSON | Compact JSON | 1 行の JSON | 说明复制后的表示形式。 |
| 只读配置 | Read-only | 読み取り専用 | 界面应清楚表达编辑内容不会保存。 |
| 事件替换关系 | Replaced by / Replaces | 置き換え先 / 置き換え元のイベント | 保留关系的方向。 |

## 开发者用语

产品名、斜杠命令、按键组合、参数名、协议值和错误代码保持原值。Git、MCP、API Key、Harness、reasoning_effort、/goal，以及命令示例中的 clear，都保留其技术含义。

操作更清楚时，保留日本软件中常用的术语：セッション、ワークスペース、プラグイン、ファイル、コピー、キャンセル、ターミナル、エージェント、ツール 和 コンテキスト。审阅依据是语境。

## 检查与审阅

`pnpm run verify-japanese-experience` 按所属词典和已经审阅的键执行检查。它会拒绝这些语境中难以理解的队列、steer 标签，以及暗示只读设置会保存的文案，同时允许技术标识和其他合理用法。正向和负向测试明确检查边界。新增规则前，应先审阅原意和实际交互。

本地语料导出保留文件、键、英文、中文、日文、占位符和调用位置。公开审阅分支只列实际修改及其界面语境。CLI 和 SDK 诊断单独标明展示归属；命令拼写、协议值、错误代码和语言 API 保持既有约定。
